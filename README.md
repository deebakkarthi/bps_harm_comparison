# bps_harm_comparison

This repository is a comparison between the rules generated by HARM and BPS.


# Meaning of Files

- `originals/` contains the unmodified files received from others.
- `csv/` contains the files after they have been converted to csv
- `scripts/` has miscellaneous scripts that serve as a shorthand to reproduce
results
- `compare.py` is the main script that performs the comparison
